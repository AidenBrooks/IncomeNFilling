# Website UI Kit — Compliance OS

Interactive click-through recreation of the revamped Income N Filing marketing site. Composed entirely from this design system's components (`NavBar`, `Footer`, `TerminalSearch`, `CommandOutputLine`, `ModuleCard`, `StatBlock`, `OfficeCard`, `DeadlineTicker`, `Accordion`, `TestimonialCard`, `Input`/`Select`/`Textarea`, `Button`/`CommandButton`, `Badge`).

Screens (hash-routed, click any nav link or CTA to navigate):
- `Home.jsx` — hero with the terminal search module and deadline ticker
- `ServicesHub.jsx` — searchable directory of the 10 service categories (94 services)
- `ServiceDetail.jsx` — flagship service template (shown: ITR Filing)
- `LiveChat.jsx` — terminal-styled chat that hands off to WhatsApp
- `Contact.jsx` — office locations + consultation form

This is a cosmetic recreation for prototyping, not production code. The full site (14 pages) should be built in a consuming project using these same components.
